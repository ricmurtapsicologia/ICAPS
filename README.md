# ICAPS 2.0

Fonte canônica do Inventário Clínico para Avaliação de Prontidão para Separação.

- `data/icaps-v2.json`: definição canônica, 60 itens, polaridade, bandas e interpretações.
- `js/scoring.js`: motor determinístico de pontuação.
- `tests/scoring.test.mjs`: testes de regra de negócio.
- As imagens Open Graph/Twitter e o banner visual continuam hospedados no Pinterest deliberadamente, preservando a função visual já existente no produto.

O ICAPS é instrumento clínico estruturado de apoio. Não constitui teste psicológico diagnóstico e não deve determinar isoladamente continuidade ou término da relação.
